# SchulApp

Eine moderne Schul-App als bessere Alternative zu WebUntis.

## Funktionen (Version 1)
- **Start:** Tagesübersicht, offene Aufgaben, kommende Tests, Notenschnitt, Neuigkeiten
- **Stundenplan:** ganze Woche mit Entfall, Vertretung und Raumänderung
- **Hausaufgaben:** abhaken, filtern, Fortschrittsbalken (wird im Browser gespeichert)
- **Noten:** Durchschnitt pro Fach und gesamt
- **Neuigkeiten:** Mitteilungen der Schule

Alle Daten sind derzeit Beispieldaten (`src/data/demo.ts`).

## Starten
```bash
npm install
npm run dev
```
Dann im Browser http://localhost:5173 öffnen.
